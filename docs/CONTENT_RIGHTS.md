# Third-party content rights register

GPL v3 covers project-authored code. It does not grant rights to a third party's recordings, translations, text compilation, trademarks or services. This register records known gaps; it is not legal clearance.

| Material | Evidence | Status / next action |
| --- | --- | --- |
| App code and original UI | Editable source, GPL v3 | Offered under the project licence. |
| Generated art/branding | Design sources and recorded prompts | Original project assets; no reference-publisher image inputs. Review service terms for your distribution. |
| WSM Sans / Plus Jakarta Sans and Amiri | Bundled SIL OFL records | Retain licences, copyright and reserved-name handling. |
| Selected Hadith API records | Bundled upstream Unlicense record | Retain provenance, edition/reference IDs and language labels; verify the selected edition. |
| Doa, wirid, niat and important-date compilation | Inherited resources; source hashes in `design/assets/reference-copies.json` | **Redistribution permission unverified.** Obtain permission or replace with a verified licensed/public-domain compilation. Do not generate religious translations. |
| `adhan_standard.mp3`, `adhan_fajr.mp3` | Inherited recordings and source hashes | **Recording redistribution permission unverified.** Obtain permission or replace with independently licensed recordings, including performer/recording rights. |
| JAKIM prayer data | Public official API, validated cache | Review current data/API terms; no institutional endorsement claimed. |
| Quran text/translations/recitation | Provider/edition references in `API_SOURCES.md` | Review each edition/recording and provider terms before offline or commercial redistribution. |
| Article/video catalog | Attribution, source links and official player | Full articles/video files are not bundled; respect embedding/thumbnail terms. |

The development source/builds retain inherited resources to preserve the working app. No permission evidence has been supplied for entries marked unverified. Public repository/API availability is not that evidence. A production distributor should resolve those entries before wider redistribution. Source privacy cleanup does not resolve content rights.

Record replacements and publishable permissions in [ASSET_PROVENANCE.md](../ASSET_PROVENANCE.md). Keep private correspondence out of Git.
