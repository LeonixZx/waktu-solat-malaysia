# Security reports

Use **Security → Report a vulnerability** on [this repository](https://github.com/LeonixZx/waktu-solat-malaysia/security/advisories/new) for private reports. Do not post tokens, personal records, signing keys, exact locations or full device logs in public issues. If private reporting is unavailable, open an issue requesting a private contact route without sensitive details.

Include the affected version, minimal reproduction, impact and a redacted example. This community project does not promise a response-time SLA. Fixes target the latest development version, currently Android 3.3.4 / PWA 3.1.0; old source tags are recovery snapshots.

CI uses read-only repository permissions and has no publisher signing keys or phone backups. Secret scanning and privacy checks supplement manual review. Checksums identify APK files; they do not replace Android signature verification. Revoke/rotate a leaked credential even after removing its file. History changes cannot recall existing copies.

See [PRIVACY.md](PRIVACY.md) for data boundaries and [CONTRIBUTING.md](CONTRIBUTING.md) before attaching diagnostics.
